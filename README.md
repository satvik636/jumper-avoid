# jumper-avoid

A fast-paced, browser-based jumping game built with static HTML, CSS, and JavaScript. Avoid obstacles, track your score, and see how long you can survive!

## 🚀 Play Live

Play the game directly in your browser:  
👉 **[Play Jump Game](https://jump-avoid.edgeone.dev)**

---

## 🎮 How to Play

1. Open the game link in any modern web browser.
2. Press `Spacebar` (or tap the screen on mobile/touch devices) to jump.
3. Avoid all incoming obstacles to stay alive.
4. Try to beat your highest score!

---

## 🛠️ Features

- **Lightweight & Fast:** Built using pure static HTML/CSS/JS with zero external dependencies.
- **Cross-Platform:** Works seamlessly on both desktop and mobile web browsers.
- **Instant Load:** Hosted on EdgeOne for fast global CDN delivery.
